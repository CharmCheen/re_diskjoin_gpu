## Core algorithm understanding

- **Bucketization** (`lib/Kmeans.h`, `lib/ClusterIO.h`): sample centers, build HNSW over centers, 2-choice assignment, write each bucket contiguously, record centroids/radii/assignment.
- **Bucket graph** (`lib/DiskJoin.h`): HNSW KNN per bucket, angle-based probabilistic truncation using `error_bound`, keep upper-triangle candidate tasks.
- **Gorder** (`lib/Gorder.h`): greedy graph reordering via incremental sibling-key updates; returns rank permutation.
- **Belady cache** (`lib/Cache.h`): precomputed future-use lists; max-heap evicts bucket with farthest next access. `LRUCache` exists but is not on the main path.
- **Execution** (`lib/DiskJoin.h`): load candidate buckets, self-join + cross-bucket L2² checks under `epsilon² = radius`, sample recall over IDs divisible by 100000.

Important caveats: the code batches all candidates of a target bucket, rather than strictly processing two buckets per edge; the paper's triangle-inequality Eq.(1) filter is not used in graph construction — this is by design, since §5.2 replaces it with HNSW KNN + probabilistic (Algorithm 3) pruning. The offline demo is pedagogical, not exact Gorder.
